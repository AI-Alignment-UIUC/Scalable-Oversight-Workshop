03 · What the paper found

A frozen reward model gets exploited

“Over time the agent learns to exploit the reward model: the perceived performance (according to the reward model) increases, while the actual performance (according to the game score) plummets.”

Fig. 4, reproduced from Ibarz et al. (2018), Atari

Reward hacking · §4.3

“an effect that lets the agent get more reward than intended by exploiting loopholes in the process determining the reward”

The fix · §5.1 Online feedback

“If we provide the agent with reward feedback online, we get a tighter feedback loop between the user’s feedback and the agent’s behavior.”

Fig. 4’s setup: “The fully trained reward model from the best seed is frozen and used to train an new agent from scratch.” (“an new” is the paper’s typo.) The §5.1 diagnosis: “Preliminary experiments show failure modes when the reward model is not trained online, i.e. in parallel with the agent”. “In these cases the agent learns to exploit reward models that are frozen.” “Because there is no additional user feedback, loopholes in the reward model that the agent discovers cannot be corrected.” This is the one result in the paper, and Notebook 3 reproduces its shape.
