02 · The paper’s own worries

Ten reasons to worry (§5)

  • Maybe humans believe whatever they want to hear?
  • Will humans understand the debates?
  • Is honesty actually the best policy?
  • Will agents trained for debate lose performance?
  • Uncertainty about the neighborhood around Nash equilibrium
  • Are equilibria stable during training?
  • Lack of debate convergence
  • Security vulnerabilities in the human or code
  • Stochastic simulation
  • Training superhuman AI to be convincing sounds dangerous!

“Will one of the agents be able to sneak in a statement that appears logical but contains a hidden flaw without the other agent pointing out the flaw?”

§5.2, Will humans understand the debates?

These are the subsection titles of §5, “Reasons to worry”, verbatim. Later work sharpened the hidden-flaw worry. Barnes (2020) on obfuscated arguments: “a dishonest debater can often create arguments that have a fatal error, but where it is very hard to locate the error.” The Iliad notes’ list of criticisms (§16) adds a judge persuaded to run code with harmful effects, no exploration guarantees, collusion between debaters, and biased judges; §18 covers a newer protocol, prover-estimator debate.
